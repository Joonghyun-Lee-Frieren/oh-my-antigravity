Native Runtime, Current Models

OmA 0.10.0 adds native plugin discovery, scoped agents, valid YAML skills, and separate lifecycle adapters for Antigravity and Gemini CLI. The default model policy preserves your host selection.

Tool outcomes are observations, not proof of acceptance. Bounded reminders guide recovery and verification without bypassing permissions or forcing another turn after stopping.

Model Profiles

Choose a model your account exposes in /model. Native profiles recommend allocations; they do not silently override host selection.

Dynamic Team Assembly

Assemble first, execute after approval.

Step Behavior
1. Analyze task shapeInfer domain, output type, risk posture, and evidence depth.
2. Build role lanesSelect domain specialists and format specialists separately.
3. Assign models + reasoningMap model profiles and teammate reasoning effort by lane risk.
4. Ask approvalPause and request explicit confirmation before autonomous team execution.
5. Run lifecycleExecute team-plan -> team-prd -> taskboard -> team-exec -> team-verify -> team-fix.

Bounded Tool-Cycle Hooks

Native eventBehavior
PostToolUseReturns {}; records compact session-local outcome metadata, never raw arguments or output.
PreInvocationConsumes a pending denial, repeated-failure or verification reminder once. Does not run tools or change models.
StopAllows termination, including errors and exhausted step budgets.

PostToolCalling is not a registered event name. Gemini compatibility uses AfterTool alongside BeforeModel and the retained AfterAgent learning filter. See the hook guide.

Troubleshooting

SymptomCheck
Plugin or agents missingInspect agy plugin list --json, /skills and /agents; restart after updates.
Hook is silentInspect /hooks and the actual staged root; use OMG_PLUGIN_ROOT for a nonstandard install.
Model differs from recommendationsCheck /model, account access and launch options. Native profiles do not override host selection.
Old state after updateReview custom model mappings and session-keyed traces; keep one hook registration per host.
